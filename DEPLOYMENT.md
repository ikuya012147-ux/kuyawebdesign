# Deployment handoff

This repository is a static HTML site. `index.html` remains the NAGI fictional demo URL, and `service.html` is the Kuya service landing page.

## Before publishing commercially

- Choose a commercial hosting provider and confirm its current terms, limits, and pricing.
- Decide the production domain. Quote domain and hosting costs before purchase or setup.
- Point the chosen host at the repository root so both `/` and `/service.html` remain available.
- Verify the Instagram profile URL, navigation, HTTPS, metadata, and mobile layout in production.

No hosting platform or paid plan is selected by this repository. Do not publish commercially until a hosting decision is made; this review branch does not select or configure a live host.
